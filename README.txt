FRET — Guitar Studio (prototype)

Files:
- index.html: app structure
- style.css: visual design
- app.js: tuner, metronome, and basic tablature editor
- manifest.json: PWA metadata

Important:
1. Upload all files to the ROOT of your GitHub repository.
2. Enable GitHub Pages from Settings > Pages, using branch main and folder / (root).
3. Open the published HTTPS address in Safari.
4. Use Share > Add to Home Screen.

Microphone tuner access requires HTTPS and permission.

This is an early prototype. The editor currently supports basic fret entry and TAB-to-note-name display.
Full standard notation editing and accurate two-way conversion are not implemented yet.
